Правила оформления коммитов (Conventional Commits):

1. feat: (новая функция/фича)
   Пример: feat: добавлена кнопка сохранения

2. fix: (исправление бага)
   Пример: fix: исправлено падение при запуске

3. docs: (изменение документации)
   Пример: docs: обновлен файл README

4. style: (форматирование, отступы, пробелы)
   Пример: style: исправлены отступы в коде

5. refactor: (рефакторинг кода без изменения логики)
   Пример: refactor: переписан метод авторизации

6. test: (добавление или изменение тестов)
   Пример: test: добавлены тесты для калькулятора
